# Security policy

## Supported status

ECO is currently an early development project. No current build is approved for real or sensitive evidence.

## Reporting a vulnerability

Do **not** disclose a suspected security vulnerability in a public issue.

Use GitHub's private vulnerability reporting feature on this repository's **Security** page once enabled. Include:

- affected version or commit;
- reproducible steps;
- expected and actual behaviour;
- impact assessment;
- a minimal synthetic proof of concept;
- no real personal evidence.

## Security principles

- offline by design;
- originals preserved and immutable;
- derived data explicitly identified;
- untrusted evidence treated as hostile input;
- no arbitrary code execution by local AI;
- no hidden network fallback;
- strict backup validation and staged restoration;
- release binaries built from public source through a controlled pipeline;
- trusted signatures required before normal end-user distribution.

## Coordinated disclosure

Maintainers will acknowledge a valid private report when capacity permits, investigate it, preserve evidence of the finding, and publish a security advisory after a fix or mitigation is available.
