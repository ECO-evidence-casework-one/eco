# Maintainers and release roles

ECO is currently maintained through the [`ECO-evidence-casework-one`](https://github.com/ECO-evidence-casework-one) GitHub organisation.

## Current role assignments

- **Author and committer:** [`Nexlu1`](https://github.com/Nexlu1)
- **Reviewer:** [`Nexlu1`](https://github.com/Nexlu1)
- **Signing approver:** [`Nexlu1`](https://github.com/Nexlu1)
- **Repository and organisation owner:** [`Nexlu1`](https://github.com/Nexlu1)

One person may hold more than one role during the early project phase. Every signing request must still be a separate manual approval after automated build and test checks have passed.

As the contributor group grows, author, reviewer and signing-approver duties should be separated where practical. The current role record must be updated whenever repository permissions change.
