# ECO partnership exploration records

This directory contains public-safe material for **non-binding exploratory discussion** with established organisations.

## Current status

- No ECO publisher, steward, partner or institutional deployment is appointed.
- No organisation named in future research should be described as interested, suitable, endorsed or approved without evidence.
- Discussion of public repository information does not transfer duties or create a partnership.
- Real evidence, private diagnostics, credentials and identifying case material must not be shared.

## Documents

- [`PARTNER_INFORMATION_PACK.md`](PARTNER_INFORMATION_PACK.md) — plain-English explanation of ECO, its boundaries, current position, organisational need and staged engagement process.
- [`EXPLORATORY_OUTREACH_TEMPLATE.md`](EXPLORATORY_OUTREACH_TEMPLATE.md) — controlled written introduction, short-form message, response record and stop conditions.

## Use stages

1. Approve the generic public-safe pack.
2. Separately research objective categories and named organisations.
3. Record why a named organisation may or may not fit, without implying interest.
4. Approve each outreach target and public contact route.
5. Send only a non-binding written introduction.
6. Record responses accurately.
7. Return any formal interest to issue #17 due diligence and governing-body acceptance.

## Prohibited use

Do not use these materials to:

- announce or imply a partnership;
- appoint a publisher or steward;
- form a company, CIC, charity or other entity;
- request or receive real evidence;
- agree a real-data pilot or institutional supply;
- transfer repository or signing authority;
- make unsupported legal, medical, forensic, security, accessibility, accuracy, compliance or release claims;
- assign organisational duties or personal liability to an individual contributor.

Completion of this directory opens no product, evidence-use, signing, release or deployment gate.
