3
Truthful processing feedback

Evidence intake shows the current stage, percentage and a real cancellation control.

4
Source-backed assistance

Ask ECO shows the current position, suggested action and named sources instead of generic chat.

5
Consistent calm visual system

Plain language, spacious cards, visible status and low-sensory mode are used throughout.
